# 経県値 calculator

Rate your experience with each of Japan's 47 prefectures from 0 to 5 and get a score out of 235.

| Pts | Level | Meaning |
|---|---|---|
| 0 | 未踏 | Never been |
| 1 | 通過 | Passed through (flying over doesn't count) |
| 2 | 接地 | Set foot: changed trains, rest stop |
| 3 | 訪問 | Walked around, no overnight stay |
| 4 | 宿泊 | Stayed overnight |
| 5 | 居住 | Lived there (about 3+ months) |

Answers are saved in your browser's localStorage only.
